
# Project Reflection 
##### To create and manage the branches, I first created a header feature branch using "`git checkout -b feature/header`" and a footer feature branch using "`git switch -c feature/footer`". After adding the required code for each feature, I saved the files, added `index.html` to the staging area, and committed the changes on their respective branches.Once both features were completed, I switched back to the main branch using "`git switch main`" and merged each feature branch into it using "git merge". During the merge process, a merge conflict occurred. I resolved the conflict in VS Code by selecting "`Accept Incoming Change`", which applied the changes from the incoming branch. After resolving the conflict, I saved the updated `index.html` file, added it to the staging area, and committed the final version on the main branch. Finally, I pushed the updated main branch to the remote GitHub repository, "[version-control-simulation-Funmi](https://github.com/IMNUF/version-control-simulation-Funmi)".
